title: Searching listings
description: Search Airbnb listings by location with date, price, guest, room-type, amenity, and bounding-box filters.

`nook search <location>` finds listings with filters for dates, price, guests, room type, bedrooms/beds, amenities, superhost, place ID, and a bounding box.
