---
title: Introduction
description: nook is a read-only, JSON-first Airbnb search and forward-availability CLI for AI agents — booking excluded by design, no auth, no evasion.
---

nook gives an AI agent (or you) clean, bounded JSON for Airbnb listing search, listing details, and a forward availability calendar (per-day available / min-nights / price) — the piece other tools don't give you for free. It never books, never logs in, and reads only public, logged-out data.
