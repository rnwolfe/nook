title: Install
description: Install nook with uvx (zero-install runs), uv tool, or pipx — a single Python CLI published to PyPI.
---

Run nook with no install via `uvx nook`, or install it for repeated / agent use with `uv tool install nook` (or `pipx install nook`). It's a single Python/Click CLI on PyPI.
